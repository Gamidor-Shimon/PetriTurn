# לוח ההלחמה — SBS PetriPlater

סידור הרכיבים על לוח חורים (Perfboard) של 30 × 60 מ"מ, שנכנס לקופסה המודפסת בצד ה-USB של המנוע.
הסידור והחיבורים מוגדרים ב-`layout.py`, **ונבדקים אוטומטית מול [WIRING.md](../WIRING.md)**:
כל חיבור קיים, אין קצר בין אותות, ופינים שאסור לחבר (PDN, CLK, D0, D6–D10, 5V) נשארים פנויים.

```bash
.venv\Scripts\python perfboard\layout.py
```

## הלוח

- לוח חורים **30 × 70**, פסיעה 2.54 מ"מ, **לקצר ל-60 מ"מ** (22 שורות).
- **עמודות A–J** לרוחב (A בצד דופן ה-USB). **שורות 1–22** לאורך.
- **שורה 1** היא השורה בקצה שנחתך. לסמן בטוש את A1 בשני הצדדים של הלוח לפני שמתחילים.
- 4 חורי הרכבה בפינות, 2.5 מ"מ מהקצוות, לברגי M2.5. בקצה שנחתך — לקדוח 2.7 מ"מ.

## הרכיבים

| רכיב | ערך | מיקום | הערה |
|---|---|---|---|
| **XIAO ESP32-C3** | על 2 × 7 שקעים נקבה | שורה 14: `A`–`G` = D0–D6 · שורה 20: `A`–`G` = 5V, GND, 3V3, D10, D9, D8, D7 | **שקע ה-USB-C לכיוון עמודה A**, בקצה הלוח |
| **TMC2209** (V985) | על 2 × 8 שקעים נקבה | עמודה `C`, שורות 10→3 = EN, MS1, MS2, PDN, USART, CLK, STEP, DIR · עמודה `H`, שורות 10→3 = VM, GND, A2, A1, B1, B2, VDD, GND | **הפוטנציומטר לכיוון ה-XIAO**, צלע קירור למעלה |
| **R1** | 1kΩ | `A12` – `E12` | שוכב על הלוח |
| **R2** | 10kΩ | `C11` – `G11` | שוכב על הלוח |
| **C1** | 100µF / 35V, קוטר 6.3, רגליים 2.5 מ"מ | **+** ב-`J10`, **−** ב-`J9` | **קוטביות!** הפס (−) לכיוון שורה 9 |
| **מחבר מנוע** | JST-XH 4 פינים | `J7` (1), `J6` (2), `J5` (3), `J4` (4) | 1 = שחור, 2 = ירוק, 3 = אדום, 4 = כחול |
| **כניסת 24V** | חוטים משקע המתח | **+24V** ל-`J12`, **0V** ל-`I8` | מולחמים ישירות, עם הידוק לקופסה |

- **השקעים הנקבה מאפשרים להחליף את הבקר ואת הדרייבר בלי הלחמה.** מלחימים את השקעים, לא את הרכיבים.
- **קבל C1 בקוטר 6.3 מ"מ** נכנס בין הדרייבר לקצה הלוח. קבל של 8 מ"מ לא נכנס.
- **הגובה של הרכיבים:** ה-USB-C של ה-XIAO יוצא בגובה 21.3 מ"מ מעל רצפת הקופסה עם שקעים נקבה של 8.5 מ"מ.
  שקעים בגובה אחר — לעדכן `USB_Z` ב-[enclosure/build_enclosure.py](../enclosure/build_enclosure.py).

## סדר עבודה

1. לקצר את הלוח ל-60 מ"מ, לסמן A1, לקדוח חורי הרכבה בקצה שנחתך.
2. להלחים **שקעים נקבה** ל-XIAO ול-TMC2209, **בלי הרכיבים עצמם**.
3. R1, R2 (שוכבים), C1 (**קוטביות**), מחבר JST.
4. גשרי הלחמה B1–B11.
5. חוטים W1–W13.
6. **בדיקה במולטימטר — לפני שמכניסים רכיבים** (טבלה למטה).
7. חוטי 24V משקע המתח: אדום ל-`J12`, שחור ל-`I8`.
8. להכניס את ה-XIAO (USB-C לכיוון עמודה A) ואת הדרייבר (פוטנציומטר לכיוון ה-XIAO).
9. בדיקה ראשונה: USB בלבד → `STATUS`. אחר כך 24V → `DIAG` צריך להחזיר `A0=12/0x21`.

## בדיקה במולטימטר — בלי רכיבים, בלי מתח

מודדים **בין החורים** (על השקעים).

| בין | צריך | מה זה בודק |
|---|---|---|
| `J12` ↔ `H10` | ≈0Ω | +24V מגיע ל-VM |
| `I8` ↔ `H9` ↔ `B20` ↔ `C8` ↔ `C9` ↔ `H3` | ≈0Ω | אדמה משותפת, MS1/MS2 ל-GND |
| **`J12` ↔ `I8`** | **נתק** | **אין קצר בין 24V ל-GND** |
| **`J12` ↔ `C20`** | **נתק** | **24V לא מגיע ל-3.3V** |
| `C20` ↔ `H4` | ≈0Ω | 3.3V ל-VDD |
| `C20` ↔ `C10` | ≈10kΩ | R2 (EN ← 3.3V) |
| `B14` ↔ `C10` | ≈0Ω | D1 → EN |
| `C14` ↔ `C4`, ‏`D14` ↔ `C3` | ≈0Ω | STEP, DIR |
| `F14` ↔ `C6` | ≈0Ω | D5 → USART |
| `E14` ↔ `C6` | ≈1kΩ | D4 → R1 → USART |
